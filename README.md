# Plex

Music client for [music.plexs.me](https://music.plexs.me).

made using Kotlin + Jetpack Compose. Streams directly from our api, u may Sign in using email OTP Verification  or Google's OAuth.

## Build

Open the project in Android Studio and run, or from the terminal:

    ./gradlew assembleRelease

No keys are needed at build time. Runtime config is fetched from the API on
first launch.

## Releases

Users gets notified about Latest updates / changes made.
